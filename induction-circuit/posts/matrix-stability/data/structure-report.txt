70M / 160M：频率结构 → 完整 C 稳定 → 位置修正 R → 竞争 margin
2026-11-04

结论
本轮完全使用 CPU，GPU=0，新模型前向=0。全部 38 个模型状态、741 个路线与 checkpoint 组合完成，独立数值控制与结果完整性检查通过。
频率通道的结构安排对完整 C 的距离稳定性有明确的矩阵层面证据；仅用矩阵算子范数和通用输入范数，还不能得到有用的实际竞争 margin 保号保证。因此整条结构性解释没有完全闭合。

范围
使用当前固定 193 路线总体中的 70M 10 条、160M 29 条路线，各 19 个 checkpoint。路线由最终 checkpoint 固定选择，不是每个 checkpoint 重新筛选。不能将结果外推到所有 heads、全部 Pythia 规模或 OLMo。
完整矩阵及参考平均使用 D=0,...,2047，均匀权重。实际序列统计中的距离不超过 100。
每条路线的原始 R 分布包含 20,849,616 个竞争比较。margin 保号的比例只在每条路线 150,000 个 query 各自冻结的一个 native-selected 正误候选对上计算；它不是全候选保号比例，也不是注意力准确率。

1. 从权重频率结构到完整矩阵
固定含归一化增益的 Q、T=KOV，C_D=Q^T R(-D) T/sqrt(h)。本轮两个规模 h=64，其中 16 维旋转、48 维非旋转。
逐平面展开：
  C_D = C_NR + sum_p [cos(D omega_p) B_p + sin(D omega_p) S_p]。
B_p、S_p 都是完整残差空间中的矩阵，不只作用在 H+ 的某个选定方向上。
令 Cbar=mean_D C_D，将各 sin/cos 减去对应距离均值，得到系数向量 z(D)。定义 Gamma_ab=<M_a,M_b>_F，则
  ||C_D-Cbar||_F^2 = z(D)^T Gamma z(D)。
这保留了通道间的交叉项，未假设各平面在残差空间正交。
非旋转项在扰动中严格消失。低频旋转项通常产生较小的相位改变量；其权重大小以及与其他项的叠加共同决定完整 C 的扰动。
算子范数使用旋转通道的 16x16 Gram 表达精确计算；未将 Frobenius 范数冒充算子范数。报告中的相对算子误差同样以 ||Cbar||_F 为分母，不能误读为以 ||Cbar||_2 为分母。

最终 checkpoint 143000，路线等权汇总：
  70M：mean_route mean_D ||C_D-Cbar||_F/||Cbar||_F = 15.52%。
  160M：上述数值 = 15.01%。
这是相对距离平均矩阵的偏移，不是任意两个距离间的直接偏移，也不保证任意输入的相对分数变化都很小。

2. 频率结构的反事实检查
最终 checkpoint 上，同时对 Q、T 做相同通道置换，交换旋转平面与非旋转通道。该操作代数上保持 C_0 不变，改变相对距离的作用路径。使用三个固定随机种子。
以 sqrt(mean_D ||C_D-Cbar||_F^2) 衡量绝对波动，置换后/原始值的路线平均比为：
  70M：10.61、11.09、12.14 倍，三次均为全部 10 条路线增大。
  160M：9.90、9.43、9.34 倍，三次均为全部 29 条路线增大。
将原有低频平面的频率设为 0，波动降至 0.826、0.848 倍；将其频率乘 4，波动增至 1.854、1.746 倍。低频集合在原始频率下冻结。
这支持非旋转/低频通道安排对完整 C 稳定性的作用。这里仅干预静态矩阵几何，未重新运行模型，不能当作注意力行为的干预结果。

3. 从完整 C 到位置修正 R
写 E_D=C_D-Cbar，冻结同一个正确候选 p 与竞争候选 j：
  m_pos = m_ref + R，m_ref=G-b+T；
  R=x^T E_Dp y_p - x^T E_Dj y_j。
对本轮归一化约定，输入范数至多 sqrt(d)，故
  |R| <= d [||E_Dp||_2 + ||E_Dj||_2] = B。
竞争候选为 BOS 时，按原始统计约定第二项为零。
若 m_ref>B，则 m_pos>0；若 m_ref<-B，则 m_pos<0。
这条不等式及已判定保号样本均通过 FP64 数值核验，未使用区间算术。

关键限制：最终 checkpoint 的算子范数界对两个规模均未认证任何正 margin，也未认证任何 margin 保号。此结果表示充分条件太松，不表示实际 margin 全部不稳定。
在同一冻结候选对上，参考与实际 margin 的观测符号不同率为 70M 1.889%、160M 1.728%。这是数据中的事实，不能由本轮通用范数界有效解释。
对全部竞争比较，通用最大 |R| 上界/观测最大 |R| 的路线平均比约为 53.5、92.5，进一步显示输入最坏情形的松弛很大。
利用已有 query 内 R 均值与标准差构造有限样本支持界，可认证冻结候选对中的正 margin 比例为 61.91%、55.18%。这个诊断依赖已经观测到的 R，不能充当由权重直接推出行为的结构性证据。

4. 已支持与未完成
已支持：完整 C 的频率分解可精确复现扰动；改变频率安排可大幅改变完整 C 的跨距离波动；矩阵扰动到 R、再到 margin 保号的条件不等式有效。
未完成：以足够紧的结构界解释真实输入上的 R 较小，以及为何有足够多 margin 能稳定保号。接下来需要输入在扰动奇异方向上的投影、query/key 与扰动的对齐，或等价的输入加权双线性界。继续只收紧通道频率的三角界不能消除通用输入范数的主要松弛。
本轮也未新增验证主特征子空间稳定性；该结论仍需独立的谱间隔与跨空间扰动证据。
